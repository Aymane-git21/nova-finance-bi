## Extracts — ready to upload

[`extracts/`](extracts/) holds the four files the SAC models are built on. Generated by `data-generator/generate.py`, committed deliberately: they are small, and they are exactly the bytes the story gets built on, so the repository holds the same data the screenshots were made from.

| File | Rows | Size | Feeds |
|---|---:|---:|---|
| `sac_pl_actuals.csv` | 1,296 | 0.1 MB | CFO overview — P&L by entity, period and account group, with manual-posting counts |
| `sac_programme_costs.csv` | 8,986 | 0.8 MB | Programme controlling — cost by programme, entity, period, account group, plus lifetime budget |
| `sac_close_tasks.csv` | 2,016 | 0.2 MB | Close monitor — every task with due/actual dates, delay, days-to-close and an open-period flag |
| `sac_budget_actual.csv` | 20,798 | 1.3 MB | **Planning model** — Actual / Budget / Forecast stacked on a Version dimension |

All are pre-aggregated and pre-joined, with signs already applied (expenses positive, revenue negative) and budget already phased evenly across twelve periods. SAC's modeller is not the place to discover that revenue needed a sign flip.

Every file also carries **`period_date`** (first day of the fiscal period) and `fiscal_period_label`. Fiscal year and period as two integers is enough to group by and useless to a time axis: without a real date column SAC builds no time dimension, so there is no hierarchy, no year-over-year, no period-range filter, and the periods sort as text with "12" landing between "11" and "2". If you uploaded an earlier copy of these files, replace it.

`sac_close_tasks.csv` contains one genuinely open period — the slow entity's most recent hard close has not completed. `days_to_close` is empty there, not zero. Any tile that renders it as zero is wrong, and it is in the data specifically so that case gets tested rather than assumed away.

## What the story should reveal

The data carries these on purpose. A story page that does not surface them is a design problem, not a data problem — measured values are in [`../docs/dataset-profile.md`](../docs/dataset-profile.md).

| Page | What a viewer should notice without being told |
|---|---|
| CFO overview | One entity drags the group's days-to-close average |
| Programme controlling | One programme's EAC crosses its budget while the other nine sit under |
| Close monitor | The same entity that closes late also posts most by hand — the mechanism, not just the symptom |
